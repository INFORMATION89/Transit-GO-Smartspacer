# Transit GO for Smartspacer

A [Smartspacer](https://github.com/KieronQuinn/Smartspacer) plugin that shows your active [Transit](https://transitapp.com) GO trip on your home and lock screen: the current instruction, the route chip, the next step with the arrival time or time left, and Transit's logo. Tapping the card opens the trip in Transit. It can also hide Transit's GO notification on the lock screen while the card is showing (with Native Smartspace), and its settings show a live preview of the card. The plugin is in English and Spanish, and the card shows Transit's own text in whatever language Transit uses.

To set it up, install the APK from the [latest release](../../releases/latest), turn on **Notification access** for *Transit GO for Smartspacer*, then add the **Transit GO** Target in Smartspacer and start GO in Transit. The plugin only reads Transit's GO notification and ignores every other notification.
